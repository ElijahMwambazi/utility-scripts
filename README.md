# Utility Scripts

A categorized toolkit of useful scripts for automation, productivity, networking, data handling, APIs, and system operations.

## Categories

- `email/` — email and messaging utilities
- `microsoft-365/` — Microsoft 365 and Graph API automation
- `system/` — Linux and Windows administration scripts
- `networking/` — network diagnostics and utilities
- `data/` — CSV, Excel, cleanup, and transformation tools
- `files/` — file-management utilities
- `automation/` — general workflow automation
- `web/` — web/API utilities
- `utilities/` — small standalone tools

## Included tools

### Outlook bulk personalized email

`email/outlook-bulk-mail/` sends a separate Microsoft 365/Outlook email to every recipient through Microsoft Graph. Recipients do not see one another and no CC/BCC list is required.

## Repository conventions

Each substantial utility should live in its own folder and include:

- a focused README
- example configuration/input files where appropriate
- dependency information
- no secrets, credentials, tokens, or real recipient data committed to Git
